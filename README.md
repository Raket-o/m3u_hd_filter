# M3U HD Filter

Утилита для фильтрации M3U-плейлистов IPTV-каналов. Автоматически удаляет HD-каналы (высота кадра ≥ 720p) и каналы с «HD» в названии.

## Возможности

- **Фильтрация по названию** — каналы, содержащие «HD» (отдельным словом), удаляются мгновенно без обращения к сети.
- **Проверка фактического разрешения** — через `ffprobe` определяется высота видеопотока; каналы с высотой ≥ заданного порога удаляются.
- **Параллельная обработка** — несколько каналов проверяются одновременно (настраивается через `--workers`).
- **Без сторонних зависимостей** — используется только стандартная библиотека Python; внешняя зависимость — утилита `ffprobe` из FFmpeg.

## Требования

- Python 3.8+
- [FFmpeg](https://ffmpeg.org/download.html) (утилита `ffprobe` должна быть доступна в `PATH`)

## Установка

Зависимости не требуются — достаточно скачать `m3u_hd_filter.py`.

## Использование

### Базовый запуск

```bash
python m3u_hd_filter.py playlist.m3u
```

Результат сохраняется в `<имя>_clean.m3u` в той же директории.

### Примеры

```bash
# Указать выходной файл
python m3u_hd_filter.py playlist.m3u -o clean.m3u

# Увеличить количество потоков для ускорения
python m3u_hd_filter.py playlist.m3u --workers 16

# Изменить порог высоты (например, удалять только 1080p+)
python m3u_hd_filter.py playlist.m3u --min-height 1080

# Режим «dry run» — только статистика, файл не сохраняется
python m3u_hd_filter.py playlist.m3u --dry-run

# Удалять каналы, которые не удалось проверить (таймаут, недоступность)
python m3u_hd_filter.py playlist.m3u --drop-on-error
```

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `playlist` | Путь к входному `.m3u` файлу | — |
| `-o, --output` | Путь к выходному файлу | `<имя>_clean.m3u` |
| `--min-height` | Минимальная высота кадра для удаления (пиксели) | `720` |
| `--timeout` | Таймаут подключения к потоку (секунды) | `10` |
| `--workers` | Количество параллельных проверок | `8` |
| `--drop-on-error` | Удалять каналы с недоступным потоком | `False` |
| `--dry-run` | Только показать статистику | `False` |

## Алгоритм работы

1. **Парсинг** — файл разбивается на каналы (`#EXTINF` + URL).
2. **Фильтр по имени** — если в названии найдено «HD», канал удаляется мгновенно.
3. **Пробирование потока** — для оставшихся каналов `ffprobe` определяет высоту видеокадра.
4. **Сборка результата** — каналы, не попавшие под удаление, записываются в выходной файл с сохранением всех метаданных.

## Примеры файлов

| Файл | Описание |
|---|---|
| `bittv.m3u` | Исходный плейлист |
| `bittv_clean.m3u` | Очищенный плейлист (результат фильтрации) |
| `bittvfull.m3u` | Полный плейлист |
| `clean.m3u` | Очищенный плейлист |
